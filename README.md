# Mobile-Application-Programming-Project-
This repository tracks the development of Mystiq, a mobile closet and outfit management app, with commit history showing progress for instructor review.

This repository contains the development of **Mystique**, a mobile app for
organizing your wardrobe and planning outfits, built for the Mobile Application
Programming course.

## About the App
Mystique lets users photograph and tag their clothing, browse their closet,
save outfits, and track how their wardrobe is used.

## Purpose of This Repository
This repo documents the full development process. The instructor can follow
our commits to see how the project progresses over the semester.
