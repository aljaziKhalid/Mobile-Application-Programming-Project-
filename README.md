Mystiq — Digital Wardrobe App
Project Overview
Mystiq is an Android application designed to help users organize their clothing items, create outfit combinations, and make better use of the clothes they already own.
The application provides a digital wardrobe where users can categorize clothing items, search their closet, create and save outfits, keep outfit drafts, view wardrobe statistics, and track how often they wear their clothes.
Key Features
•	Digital Closet: Organize clothing items into categories.
•	Clothing Scanning: Capture or add clothing photos and provide item details.
•	Item Tagging and Search: Name, categorize, tag, and search clothing items.
•	Outfit Builder: Combine clothing items to create complete outfits.
•	Saved Outfits and Drafts: Save completed outfits and keep unfinished combinations as drafts.
•	Wardrobe Statistics: View clothing category distribution and color statistics.
•	Wear Tracker: Track clothing usage and identify underused items.
